2. اعتمد جدول المصالحة أعلاه كمصدر dry_run لتحديد أرصدة العملاء المراد ترحيلها إن قررت بدء فترة جديدة.
3. قبل أي قيد افتتاحي: أنشئ snapshot إلزامي للزيارات/المركبات/الذمم، وسجل cleanup_run_id دائم، وتقرير قبل/بعد.
4. إذا تم إنشاء opening receivables لاحقاً، يجب تعطيل أثر البنود التاريخية مالياً أو تعليمها archive_non_posting حتى لا تتضاعف الذمم.
5. تحصيل جديد يجب أن يطبق على الرصيد المرحّل أو بنود الزيارة الحالية مرة واحدة فقط عبر `finance-engine`، مع journalEntryId/idempotency.
