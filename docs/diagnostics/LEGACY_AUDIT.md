# G3 — Silent Fallback (محلل النوايا يفشل صامتاً) — توثيق بلا إصلاح

**التاريخ:** 2026-02 | **القرار:** مؤجَّل بأمر المالك — تسجيل الدليل فقط، لا إصلاح الآن.

## الدليل (ملف/سطر)

| # | الموضع | السلوك | الخطر |
|---|---|---|---|
| G3.1 | `core/assistant_kernel.py` سطر 792–794 | `unified_executor.execute_text()` يرمي استثناءً → `except Exception` يسجّل warning في اللوق فقط ويجعل `exec_res = None` → **يسقط للمسار القرائي/LLM صامتاً** | مستخدم طلب إجراء كتابة (إنشاء/حذف/إقفال) والمحلل انهار → يستلم رد دردشة عادي **بلا أي إشارة أن الأمر لم يُعامل كإجراء** |
| G3.2 | `core/assistant_kernel.py` سطر 799 | `exec_res.status in ("read_only","rejected","error")` → تعليق صريح: «fall through to the normal read path» — حتى حالة **error** تسقط صامتة | فشل تنفيذ حقيقي (error) يُخفى خلف رد LLM طبيعي |

## التصنيف
**خطر (Silent Drop)** — ليس كوداً ميتاً؛ مسار حي يبتلع الفشل.

## الإصلاح المقترح (بانتظار اعتماد المالك — غير منفَّذ)
1. عند استثناء `execute_text` لرسالة صنّفها `looks_like_action()` ككتابة: ردّ صريح «تعذّر تحليل الأمر كإجراء — لم يُنفَّذ شيء» بدل السقوط للـ LLM.
2. تسجيل الحدث في الـ trace: `intent="action_parse_failed"` + نص الاستثناء.
3. حالة `status == "error"`: نفس المعاملة (رد صادق + trace) بدل المسار القرائي.
